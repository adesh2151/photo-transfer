Which Mac do I have? Click the menu → About This Mac. If it says "Apple M1/M2/M3/M4" → Apple Silicon; if it says "Intel" → Intel Mac.

First launch may show an "unknown publisher" warning (the app isn't paid-code-signed) — choose Run anyway (Windows) or right-click → Open (Mac). It's safe; the code is open on GitHub.

Installation guide

Install on the computer that receives the files. Pick your system:

🪟

Windows

  1. Download PhotoTransfer-windows.zip and unzip it (right-click → Extract All).
  2. Open the PhotoTransfer folder.
  3. Double-click PhotoTransfer.exe.
  4. If Windows SmartScreen appears: More info → Run anyway.
  5. Your browser opens showing a QR code — you're ready.
🍎

macOS

  1. Download PhotoTransfer-macos.zip and unzip it (double-click).
  2. Right-click Photo Transfer.app → Open (first time only).
  3. In the warning, click Open again.
  4. Your browser opens with a QR code — done.
🐧

Linux

  1. Download PhotoTransfer-linux.zip and unzip it.
  2. Open the PhotoTransfer folder.
  3. Double-click PhotoTransfer (or run ./PhotoTransfer in a terminal).
  4. If it won't run: right-click → Properties → Allow executing as program, or chmod +x PhotoTransfer.
  5. Your browser opens with a QR code — ready.
📱 On your phone: make sure it's on the same WiFi as the computer, open the Camera, point it at the QR code on the computer screen, and tap the link that appears. No app install needed on the phone.

How to use it

Three steps. The whole thing takes about a minute.

Open it on the computer

Double-click the app. A window opens showing a QR code.

Scan with your phone

Same WiFi. Open the Camera, point at the QR, tap the link.

Send or receive

Pick photos and tap Upload — or grab files the computer has. Done.

Questions

Does my internet provider or the cloud see my photos?

No. The transfer happens on your local WiFi, phone → computer. It never goes out to the internet, so your provider and the cloud aren't involved.

Do both devices need the same WiFi?

Yes — that's the only requirement. The phone and the computer must be on the same WiFi network.

Do I need to install anything on my phone?

No. The phone just opens a link (or scans the QR). You can optionally tap "Add to Home Screen" to keep it like an app.

Is it safe?

It's open source, runs only on your network, and is protected by an access code. You can also turn on encryption (HTTPS) and device approval. Nothing leaves your WiFi.
